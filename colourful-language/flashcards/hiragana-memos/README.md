# Hiragana memo images

These 66 images were extracted from the back fields of the 46 notes in the user-supplied `Japanese - Hiragana memo.apkg` deck and encoded as lossless WebP. Artwork, dimensions, and attribution in the images are preserved. The deck and its database are not published.

`../hiragana-memos.js` associates each basic hiragana character with all images on its Anki note. The deck labels SI, TI, TU, and HU are presented as shi, chi, tsu, and fu. The unlabeled N card maps to ん.

Small hiragana and characters with dakuten or handakuten use the corresponding basic character's memo with an explanatory note. Katakana, kanji, and the prolonged-sound mark do not open hiragana memos.

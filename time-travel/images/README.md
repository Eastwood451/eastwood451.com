# Evolution illustrations

Generated with the built-in image generation tool for the two time-travel lineage cards. These are artistic, representative reconstructions, not verified portraits of direct ancestors. Existing shared-stage illustrations are reused from `biology/evolution-timeline/images`.

[lineage-atlas.png](lineage-atlas.png) is a 4-column × 3-row atlas; CSS displays one square cell at a time. Reading order: modern European white-tailed eagle, ancestral sea eagle, ancestral accipitrid, early crown bird; early avialan, bird-line archosaur, early sauropsid, early Homo; early ape, early primate, early mammaliaform, cynodont.

[modern-human-man.png](modern-human-man.png) is the current illustration: a modern adult white European-looking man in contemporary clothing, as requested by the user. Created with the built-in image generation tool by editing the earlier [modern-human.png](modern-human.png), which is retained as the original. Clothing is not intended as a reconstruction for the entire 0–300,000-year display interval. The edit prompt is saved in [modern-human-man-prompt.txt](modern-human-man-prompt.txt).

The complete prompts used with the built-in image generation tool are saved in [generation-prompts.txt](generation-prompts.txt).

Scientific background and uncertainty are documented in the expandable note in the application. Interval boundaries are schematic display bins, not claims that named fossil species lived throughout those intervals.

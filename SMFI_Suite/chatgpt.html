Henter din forbindelse…

Tilføj forbindelsen i ChatGPT

  1. Åbn Plugins, og vælg Add custom MCP server.
  2. Navn: SMFI Nested Actor
  3. Server URL:
    https://eastwood451.com/api/smfi/mcp
  4. Vælg OAuth, og opret pluginet. Godkend dit diagram, når denne side åbner igen.

Vælg pluginet i din ChatGPT-samtale, og skriv: Læs mit SMFI-diagram.

Brug det samme diagram i Grok

  1. Åbn Grok Connectors → New Connector → Custom.
  2. Brug samme serveradresse som ovenfor, og vælg OAuth.
  3. Hvis Grok beder om Client ID, klik her:

    Client ID:

    Client Secret: tomt. Token Auth Method: none (PKCE only).

    Authorization URL:
    Token URL:
    Scopes:

  4. Tryk Connect, og godkend adgangen på denne side i samme browser.

Samtalen foregår i dit ChatGPT- eller Grok-abonnement med dets almindelige brugsgrænser. Denne forbindelse kalder ingen separat AI-model og kræver ingen model-API-nøgle.
